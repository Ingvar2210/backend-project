01 · The basic idea

BOOTSTRAP

Start with a system

Bootstrap supplies a grid, components such as navbars and buttons, and utility classes. Its recognizable defaults help build common interfaces quickly.

Trade-off: a distinctive design often needs custom CSS or Sass overrides.

TAILWIND

Compose small utilities

Tailwind provides single-purpose classes for spacing, color, layout, and states. You assemble the interface directly in markup.

Trade-off: markup can become long; reusable components help when patterns repeat.

Choose Bootstrap for a conventional dashboard or form-heavy prototype using its existing components. Choose Tailwind for a distinctive interface where you want direct control over many visual details.

02 · Responsive layouts

Both use mobile-first minimum-width breakpoints. Bootstrap's md starts at 768px; Tailwind's default md starts at 48rem (768px with a 16px root font). Base styles apply below that threshold.

03 · Motion and interaction

Hover this card, or focus it with the keyboard. Both Northstar designs lift their feature cards and show a shadow. Bootstrap uses a custom CSS rule; Tailwind uses utility classes.

Bootstrap + custom CSS
.feature { transition: transform .25s,
  box-shadow .25s; }
.feature:hover { transform: translateY(-6px); }
Tailwind utilities
class="transition-all duration-300
  hover:-translate-y-1.5 hover:shadow-xl"

Bootstrap includes transitions in certain interactive components, but a custom card animation still needs CSS. Tailwind has transition and animation utilities; more complex sequences can use custom CSS. This guide respects reduced-motion settings.

04 · Color themes

Switch this guide's palette. In the actual project, Bootstrap's purple button is customized with CSS variables, while Tailwind's purple bg-brand comes from a @theme token.

Accent

Bootstrap's built-in color modes
<html data-bs-theme="dark">
<!-- component colors follow mode -->

Bootstrap 5.3 supports data-bs-theme for light and dark modes; Sass and CSS variables allow deeper customization.

Tailwind theme token + variant
@theme { --color-brand: #6558d9; }
<div class="bg-brand dark:bg-slate-900">

Tailwind 4 defines color utilities from @theme; the dark: variant can respond to system preference or a configured selector.

This toggle demonstrates CSS variables in the learning page. The two Northstar pages use the same light palette and do not include a dark-mode toggle.

Plain CSS has no framework dependency and offers full control, but you write and maintain the layout and component styles yourself. Frameworks still produce CSS; they provide conventions and reusable tools, not a replacement for understanding CSS.
